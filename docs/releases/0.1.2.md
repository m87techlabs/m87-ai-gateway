# M87 AI Gateway 0.1.2

*Released 2026-11-04*

Know what you are running.

### What's new

- **Version in the console:** the sidebar shows the running version and commit, or `local build` when
  built from a checkout. Select it to open that version's release notes.
- **Release notes in the repository:** each version now has a page under
  [`docs/releases`](https://github.com/m87techlabs/m87-ai-gateway/tree/main/docs/releases), which is also
  the text of its GitHub release.
- `GET /admin/api/about` returns the running version and commit, for operators.

### Fixed

- The console could return to a signed-in view just after a session expired.
- Readiness and startup messages named pages the console no longer has.

### Upgrade

This version does not change the database. Download its Compose file, then update:

```bash
curl -fsSLO https://github.com/m87techlabs/m87-ai-gateway/releases/download/v0.1.2/docker-compose.yml
docker compose pull
docker compose up -d
```

From a checkout, run `git pull` and `docker compose up -d --build`.

### Known limitations

The same as [0.1.1](https://github.com/m87techlabs/m87-ai-gateway/blob/main/docs/releases/0.1.1.md#known-limitations).
In particular, it is not ready for direct internet exposure.
