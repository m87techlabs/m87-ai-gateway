Configuration history
Review and restore console-managed settings. The latest 100 revisions are retained. Restoring creates a new revision and clears the response cache. Credentials, application keys, logs and usage are excluded. Retention changes can delete old logs; restoring cannot recover deleted data.

      

      

        
Storage health
Verification checks SQLite integrity and rolls back a test write. It may briefly contend with other database writes. No repair or migration is performed. Back up before upgrading or recovering storage.
